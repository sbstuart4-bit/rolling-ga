# Public demo walkthrough

Marketing visitors never use the internal demo board (`/demo`). They enter one of two guided journeys for **Marisol Reyes · Brooklyn · A Tender Night**.

## Fan journey (~4–5 min)

- **Entry:** Homepage “Experience Marisol’s Show”, nav “Try the Demo”, `/home#experience-demo`
- **Persona:** Scott Weller (demo fan), no signup
- **Chrome:** Mobile fan app + presenter panel on desktop
- **Steps:** Discover show → tour merch → verify at venue → purchase → credential → post-show → returning fan (`marisol-tender-night`)

## Artist journey (~2–4 min)

- **Entry:** Homepage hero “Experience the Demo”, “Explore the Artist Studio”, secondary marketing CTAs
- **Persona:** Elena Vasquez (Marisol merch manager)
- **Chrome:** Artist Studio + guided step panel
- **Steps:** Live command center → show economics → fan cohort → activation → observed value → conclusion (`marisol-artist-studio`)

## Exiting

- **Public hosts:** Exit / end of journey returns to `/home`
- **Demo board access:** Exit returns to `/demo` for persona switching and scenario controls

## Internal QA

- Demo board: `/demo` (scenario engine, clock, all personas)
- Guided chooser (legacy): `/demo/guided`
